## Physical Definition — Reciprocal Equivalence

HSP k-point matching in `StandardIrrepTable.match_kpoint_label()` uses
centering derived from the irreptables space-group name (e.g. "P3" → P,
"C2/c" → C), not from HSP coordinate content.  The centering-aware
`_kpoint_matches_centered()` enforces the correct conventional reciprocal
lattice conditions:

- **Primitive (P)**: component-wise modulo-1 comparison (all integer
  reciprocal vectors are valid).
- **C-centered**: additionally requires h + k even.
- **I-centered**: additionally requires h + k + l even.
- **F-centered**: additionally requires h, k, l all same parity.

This eliminates the critical regression where primitive tables P1, P2, P3,
P4 with half-integer HSP coordinates were misclassified as C-centered.

## Physical Definition — EBR Completeness

One EBR problem instance groups by canonical `(SG number, SG symbol, valley)`
identity.  The `hsp_basis_status` field is `"sampled_basis"` when the
expected HSP set derives from actual candidate irreps; it distinguishes
sampled-basis readiness from validated reduced-EBR-table completeness.
Promotion to final valley-resolved output requires a reviewed
irreptables-derived reduced table.  `workflow_paths` and `readiness_evidence`
record aggregate provenance without using computational workflow as a
grouping quantum number.
